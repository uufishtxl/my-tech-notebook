### Q6. [错题复习] `strip()` 的行为
`s = "  hello world  "`，`s.strip()` 输出什么？如果 `s = "xxhelloxx"`，`s.strip('x')` 输出什么？

**答案**: 会是 `hello`，因为会像剥洋葱一样将指定字符串包含的所有字符在首尾去除。<font color="red">❌ 错误</font>
<br><font color="#1e90ff">💡 解析：这里有个小陷阱！`strip()` 默认去除**空白字符**（空格、换行、制表符）。所以 `s.strip()` 是 `"hello world"`。`s = "xxhelloxx"`，`s.strip('x')` 才是 `"hello"`。你把第一问答错了，`s` 是 `"  hello world  "`，strip 后是 `hello world` 不是 `hello`（中间空格保留）。</font>

### Q7. [错题复习] `raise_for_status()`
如果服务器返回 404，`response.raise_for_status()` 会怎样？不调用它会怎样？

**答案**: 过 <font color="red">❌ 未作答</font>
<br><font color="#1e90ff">💡 解析：这是 Requests 库的一个重要特性和最佳实践！
1. **默认行为**：`requests.get()` 只要收到了服务器响应（哪怕是 404 Not Found 或 500 Server Error），都不会抛出 Python 异常。这意味着如果你不检查 `response.status_code`，代码会继续往下跑，导致逻辑混乱。
2. **raise_for_status()**：这个方法的作用是 **"如果不成功（4xx/5xx），就主动报错"**。它会检查状态码，如果是 400-599 之间，就会抛出 `requests.exceptions.HTTPError`。
3. **最佳实践**：除非你确实要处理 404 页面内容，否则建议在请求后紧跟这一行，确保 "Fail Fast"（早报错早发现）。</font>

### Q8. [错题复习] 正则表达式 Greedy vs Non-greedy
`re.findall(r"<div>.*</div>", text)` vs `re.findall(r"<div>.*?</div>", text)`。分别输出什么？解释 `*` 和 `*?` 的区别。

**答案**: `*`表示贪婪，遇到最后一个 `</div>` 才会停止`*?`表示非贪婪，遇到第一个 `</div>` 后就会停止。
<br><font color="#1e90ff">✅ 正确。贪婪模式尽可能多匹配，非贪婪尽可能少匹配。</font>

### Q9. [错题复习] `re.match()` vs `re.search()`
`text = "hello world"`，`re.match(r"world", text)` 和 `re.search(r"world", text)` 分别输出什么？为什么？

**答案**: `re.match()`是 `None`，因为它必须从头部匹配。`re.search()`会有具体匹配到的结果，它是全文匹配。所以一般除非特殊情况必须从头匹配，否则都用 `re.search()`
<br><font color="#1e90ff">✅ 正确。这是一个非常经典的 Python 面试题。</font>

### Q12. [错题复习] Vue `key` 的作用
在 `v-for` 中为什么要绑定 `:key`？如果不绑定或者用 `index` 作为 key 会有什么问题？

**答案**: 这题昨天忘记看分析了。<font color="red">❌ 这是一个极其重要的 Vue 概念！</font>
<br><font color="#1e90ff">💡 解析：
1. **主要作用**: 给 VDOM diff 算法提供唯一标识。当数据变化时，Vue 可以用 key 准确追踪哪个元素被修改/移动/删除，而不是暴力重建 DOM。
2. **不绑定的后果**: 默认使用“就地更新”策略。如果列表项顺序改变，Vue 只会更新文本内容，而不会移动 DOM 元素。这会导致**子组件状态丢失**（比如 input 输入框里的内容、动画状态等）。
3. **用 index 的问题**: 如果列表发生**删除**或**插入**，index 就会错乱，导致后面所有元素的 key 都变了，Vue 会误以为所有组件都变了，导致不必要的全量更新或状态错位。</font>

### Q14. [新题] TypeScript `Partial<T>`
如何用内置工具类型创建一个"所有字段都可选"的 `User` 类型？

**答案**: 
```TypeScript
type Partial<User> = {
	[P in keyof User]?: User[P]
}
```
<font color="#1e90ff">✅ 正确。Mapped Types `[P in keyof T]` 加上 `?` 就是核心。</font>

### Q15. [新题] HTTP 状态码
简述：200, 201, 400, 401, 404, 500

**答案**: 
- 200: GET Success (OK)
- 201: Created (POST 创建资源成功)
- 400: Bad Request (参数错误/格式错误)
- 401: Unauthorized (未登录/Token 失效)
- 404: Not Found (资源不存在)
- 500: Internal Server Error (服务器崩了)
<font color="#1e90ff">✅ 正确。满分！</font>
