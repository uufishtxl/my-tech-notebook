### Q7. [Vue] Reactive 解构丢失响应性
**问题**：为什么 `const { count } = reactive(...)` 会丢失响应性？如何避免？

> **用户回答**: 因为这时候count只是一个普通的对象... 不清楚如何避免。
>
> **评分**: ⚠️ (5/10)
>
> **解析**:
> - 原因正确：解构出的基本类型失去了 Proxy 代理。
> - **避免方法**: 使用 `toRefs(state)` 将所有属性转换为 Ref，例如 `const { count } = toRefs(state)`。
