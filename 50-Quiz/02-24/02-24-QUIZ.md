### Q1. [Vue] Script Setup Generics
How do you declare a generic type parameter (like `T` and `U`) for a Vue component exactly using `<script setup>` so that `defineProps` can use it? (Pay close attention to the spelling of the attribute!)

**答案**: 如下：
```vue
<script setup generic="T extends {id: string}, U">
const props = defineProps({
	data: T[]
	callback: (item: T) => U
})<>
</script>
```

> 💡 **解析**：**[x] 拼写终于对了！但 defineProps 语法有误**。
> `generic="T..."` 这次拼对了，恭喜！🎉 不过 `defineProps` 的泛型写法应该是尖括号 `defineProps<{ ... }>()`，而不是 `defineProps({ ... })<>`。正确写法：
> ```vue
> <script setup lang="ts" generic="T extends {id: string}, U">
> const props = defineProps<{
> 	data: T[]
> 	callback: (item: T) => U
> }>()
> </script>
> ```
> 核心拼写已经对了，语法属于小笔误。算作通过，晋升 Box 2。

### Q2. [New: Vue/Events] Global Event Lifecycle
When attaching an event listener to the global `window` object inside the `onMounted` hook of a Vue component, what two major "unexpected issues" will absolutely occur if you fail to remove it in the `onUnmounted` hook?

**答案**: 一个是随着组件的重新挂载，会添加成百上千个一样的事件侦听；其次是当触发事件时，这些成百上千个callback都会被调用，这是灾难级的。

> 💡 **解析**：**[x] 回答正确，完美掌握了"幽灵触发"的概念**。

>
> 你的答案覆盖了第 1 点并且描述得很生动准确。第 2 点（内存泄漏）下次也记得提一下。晋升 Box 2。

### Q3. [New: Django/Auth] AUTHENTICATION_BACKENDS

### Q4. [New: Windows/DevOps] Bypassing Execution Policies
In a Windows environment, if running an installed executable script (like `uvicorn` or `huey_consumer` via `.venv\Scripts\`) gets blocked by security or execution policies, what is the standard Pythonic workaround to execute the module directly without calling the `.exe`?

**答案**: 通过 `python` 来运行 `uvicorn`，因为 `python` 在 Windows 看来是安全的。

> 💡 **解析**：**[x] 核心概念完全正确**。
> 具体的命令语法是 `python -m uvicorn ...`（即 `python -m <模块名>`）。通过 `-m` 参数让 Python 解释器自身去加载并执行模块，绕过了 Windows 对 `.exe` 入口脚本的执行策略限制。晋升 Box 1（作为新知识卡片进入日常队列）。

## 🌟 今日新知 (New Knowledge)

### 1. Windows/DevOps: `python -m` 绕过执行策略
- **场景**：在 Windows 上（尤其是 PowerShell 执行策略严格时），直接运行 `.venv\Scripts\uvicorn.exe` 等第三方脚本入口可能被安全策略拦截。
- **解法**：使用 `python -m <模块名>` 让受信任的 `python.exe` 本身来加载和执行模块代码。
- **例子**：`python -m uvicorn whisper_api:app --reload --port 8001`
- **原理**：操作系统看到的进程是"受信任的 python.exe"，而非不认识的第三方 .exe 脚本封装器。这也是 Python 官方推荐的跨平台可移植执行方式。
