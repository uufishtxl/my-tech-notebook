### Q3. [Vue] Reactivity Destructuring

### 1. Vue Reactivity Destructuring (Q3)
> **Refinement**: `watch(() => count, ...)` works if `count` is a ref, but `const { count } = props` extracts a primitive value (if count is number), so it loses reactivity entirely.
> **Best Practice**:
> - Use `props.count` directly.
> - Or use `toRefs(props)`: `const { count } = toRefs(props)`.
> - Or use Vue 3.3+ Reactivity Transform (experimental/removed) or the new `defineModel`.

### 2. Context Manager __exit__ (Q7)
> **Clarification**: `__exit__` returning `True` **suppresses** the exception (swallows it), program continues. Returning `False` or `None` (default) allows the exception to **propagate** up.

### 3. DRF Validation Order (Q13)
> **Correction**: `full_clean()` (Model validation) is **NOT** called automatically by Serializers unless you explicitly call it or use `ModelSerializer`.
> **Standard Order**:
> 1. `to_internal_value` (Field deserialization & basic type check)
> 2. `run_validation` -> calls `validate_<field>`
> 3. `run_validation` -> calls `validate()` (Object-level)
> 4. `run_validators` (List validators)

### 4. Cosine Similarity (Q15 - New)
> **Formula**: `(A . B) / (||A|| * ||B||)` (Dot product divided by product of magnitudes)
> **Range**: `[-1, 1]`. For text embeddings (usually non-negative), it's `[0, 1]`.
> **Why better than Euclidean?**: Euclidean distance is sensitive to vector **magnitude** (document length). Cosine similarity measures the **angle** (direction/semantic content), so a short sentence and a long paragraph with similar meaning will have high cosine similarity (close to 1), but might have large Euclidean distance.

### 5. Floating Point Order Strategy (Q16 - New)
> **Missing Detail**: The Agent's strategy (and our implementation) is **bidirectional**:
> - **Forward (Chunk 82 -> 83)**: Insert at the **BEGINNING** of target (`first_order - 1.0`).
> - **Backward (Chunk 84 -> 83)**: Insert at the **END** of target (`last_order + 1.0`).
> This ensures sensible placement when moving lines between chunks regardless of direction.
