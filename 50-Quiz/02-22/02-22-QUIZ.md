### Q1. [Database] 事务隔离级别 (RU->RC->RR->S)

**答案**: Read Committed

## 🌟 今日新知 (New Knowledge)

### 1. Django 安全: SECRET_KEY
- **概念**：Django 项目里的终极安全锁钥。它是一个随创建生成的极高强度的随机加密哈希串。
- **作用域**：主要参与 Django 会话存储（Session）、签名 Cookie 数据验证、密码重置校验算法及所有签名生成（如 `signing` 模块）。
- **风险**：一旦黑客窃取该字符串，可以通过签名伪造 Session 数据，直接制造任意已登录用户的请求；也可能造成 CSRF 与重置密保令牌直接被解密伪造。**不要通过 git 上传**。

### 2. Python 效率: yield (Generator) 原理
- **概念**：使用 `yield` 的函数叫生成器（Generator）。当函数运行到 `yield`，它并非像 `return` 彻底清理栈内存就退出；它是"按了一下暂停键"，把当前所有局部变量挂起，抛出一个数据给外侧使用。
- **价值**：处理海量数据。如果我要处理一个100万行的数据库，用普通的列表 Append 再 Return 的方式，内存会直接把 100万行顶满导致服务器崩溃或者 OOM！有了 `yield`，你可以每次查一小片，循环处理一行丢一行，内存消耗恒定在几 MB 水平，极其优雅优越。
