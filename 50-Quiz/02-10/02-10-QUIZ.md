### Q5. [Python] \_\_slots\_\_ 继承
如果父类定义了 `__slots__` 而子类没有定义，子类的实例是否会有 `__dict__`？这对内存优化有什么影响？

**答案**: 除非子类也定义 `__slots__`，否则仍然会有 `__dict__`，因此内存不会优化。 ✅
> 💡 **补充**：而且子类的 `__dict__` 会包含所有未在父类 `__slots__` 中定义的属性，导致父类的优化也大打折扣。

### Q6. [DRF] Validation Order
当调用 `serializer.is_valid()` 时，Field-level validaton (`validate_<field>`) 和 Object-level validation (`validate()`) 哪个先执行？

**答案**: `validate_<field>`先执行。一般执行顺序是：
- 先是有`default`或允许为空的检查
- 然后是对 field-level 验证
- 然后是对联合键的验证
- 然后才是 Object-level validation。 ✅
> 💡 **精准**：顺序完全正确。

### Q8. [CSS] 兄弟选择器
CSS 选择器 `A + B` 和 `A ~ B` 有什么区别？如果想选择 A 元素 **之前** 的 B 元素（父级相同），目前 CSS 原生支持吗？

**答案**: 一个是相邻选择器，一个是兄弟选择器。A+B只对前面紧邻A元素的 B 有效。而A~B 对所有 A 后面的 B 元素有效。有，可以用 `has`，比如 `button:has(+ button:hover)` ✅
> 💡 **点赞**：`has()` 确实是现代 CSS 的杀手级特性，实现了“父选择器”和“前兄弟选择器”的效果。

### Q9. [Django] Filter \_\_in
Django ORM 中，如何查询 `status` 字段的值在 `['active', 'pending']` 列表中的所有记录？

**答案**: `targets = SomeModel.objects.filter(status__in=['active', 'pending'])` ✅

### Q10. [Vue] defineProps
在 `<script setup lang="ts">` 中，定义 props 有 `defineProps({...})`（运行时声明）和 `defineProps<{...}>()`（类型声明）两种方式。哪一种是 Vue 官方推荐的？为什么？

**答案**: 不知道，我喜欢用后一种。
> 💡 **解析**：**推荐使用后一种（纯类型声明）**，即 `defineProps<{ msg: string }>()`。
> 1.  **类型推导更强**：直接利用 TS 类型系统，不需要手动写 `type: String` 等运行时构造函数。
> 2.  **IDE 支持更好**：配合 Volar 插件，能提供更精准的自动补全和类型检查。
> 3.  **代码更简洁**：符合 TypeScript 的直觉。

### Q11. [Django] JSONField Query
假设有一个 `data = models.JSONField()`，其中存储了 `{"settings": {"theme": "dark"}}`。如何使用 Django ORM 查询所有 theme 为 dark 的记录？

**答案**: 不太清楚。
> 💡 **解析**：Django 对 JSONField 提供了强大的双下划线路径查询支持。
> **查询方法**：`Model.objects.filter(data__settings__theme='dark')`
> 
> **注意**：
> 1.  这种查询是数据库原生的（PostgreSQL 支持最好，MySQL 5.7+ 也支持）。
> 2.  可以直接链式调用 key 名来深入 JSON 结构。

### Q12. [Python] Pathlib
相比于传统的 `os.path.join`，Python 3 的 `pathlib.Path` 有什么明显的优势？（举一个操作便利性的例子）

**答案**: `pathlib`的 Path 是一个对象，`os.path.join`是一个字符串。当想要获取 pathlib 创建的 Path 对象的文件名、扩展名时，直接通过属性就能读取，但是 os.path.join 就会比较麻烦。 ✅
> 💡 **示例**：
> `p = Path('/etc/hosts')`
> `p.exists()` (检查存在)
> `p.read_text()` (直接读文件内容，不用 open/close)
> `p / 'subfolder'` (用除号拼接路径，非常优雅)
