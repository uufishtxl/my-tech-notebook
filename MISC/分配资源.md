如果你只敲 `docker run ... ubuntu:22.04`，Docker 默认是极其慷慨的。它允许这个集装箱**跑满**你宿主机（Windows）的所有 CPU 核心，吃光所有的空闲内存。对于你在本地跑简单的 Python 脚本来说，这通常没问题。

**“上帝模式”的硬核限制：** 如果你今天要在沙盒里跑一个极度耗费资源的 AI 模型或者死循环脚本，怕它把你的电脑卡死，你可以直接在咒语里加上“紧箍咒”参数：

```DOS
docker run -it --rm --cpus="2.0" --memory="4g" -v "%cd%":/workspace -w /workspace ubuntu:22.04 bash
```
- `--cpus="2.0"`：死命令，这个集装箱最多只能征用你电脑的 2 个 CPU 核心算力。
- `--memory="4g"`：死命令，内存使用一旦超过 4GB，内核会立刻拔掉它的电源（触发 OOM Kill），你的 Windows 连风扇都不会多转一下。
