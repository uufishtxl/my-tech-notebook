# Pi-Coding-Agent 入门指南 (IndyDevDan pi-vs-claude-main)

这是一份针对具有 Python 和 Frontend 背景的初学者的快速入门手册，旨在帮助你快速理解 `pi` 的扩展机制、TUI 框架以及如何优化开发环境。

## 1. 快速启动与环境优化

为了避免每次手动输入长命令（特别是包含 API Key 的 Docker 命令），推荐使用 `Justfile` 和 `.env` 文件的组合。

### 1.1 使用 .env 存放敏感信息
在项目根目录下创建一个 `.env` 文件：

```bash
# .env
MINIMAX_CN_API_KEY="你的真实密钥"
# 其他可选的 Key
# ANTHROPIC_API_KEY=xxx
# OPENAI_API_KEY=xxx
```

### 1.2 使用 Justfile 简化流程
在项目根目录的 `justfile` 中添加 `lab` 命令，并设置 Windows 下的默认 Shell：

```just
set dotenv-load := true
set windows-shell := ["powershell.exe", "-NoLogo", "-Command"]

# 进入 Docker 沙盒环境
lab:
    docker run -it --rm `
        -v "${PWD}:/workspace" `
        -v "${HOME}/.pi:/root/.pi" `
        --env-file .env `
        my-pi-lab bash
```

**使用方法：** 在宿主机终端运行 `just lab` 即可。

## 2. 核心概念拆解

对于只熟悉 Python 和前端的开发者，可以这样理解 `pi` 的核心：

### 2.1 什么是 `ctx` (Context)?
`ctx` 是 `pi` 引擎传递给每个扩展脚本的**上下文工具包**。
- **类比前端**：类似浏览器里的 `window` 对象或 React 的 `Context`。
- **组成部分**：
    - `ctx.ui`：控制终端底部的状态栏、侧边栏或显示通知。
    - `ctx.agent`：获取当前 AI 模型的状态和信息。
    - `ctx.events`：监听键盘快捷键。

### 2.2 什么是 TUI (Terminal User Interface)?
TUI 就是“在黑框框里画 UI”。
- **开发思维**：你可以把它想象成通过 CSS `absolute` 定位来排列组件，只不过坐标单位不是 `px`，而是字符的**行**和**列**。

### 2.3 Bun 的角色
`pi-vs-claude-main` 项目依赖 **Bun** 作为运行时，因为它处理 TypeScript 的速度极快。建议在容器内也安装 Bun，以获得最佳体验。
