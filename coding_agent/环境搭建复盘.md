# 环境搭建复盘汇总

记录从零搭建 `pi-coding-agent` 沙盒环境过程中的关键步骤与踩坑经验。

## 1. 核心改进策略
*   **指令自动化 (Justfile)**：用 `just lab` 替代了复杂的 `docker run` 命令。
*   **敏感信息分离 (.env)**：通过 `.env` 管理 API Key，避免在命令记录中暴露密钥。
*   **开发环境对齐**：在 `Dockerfile` 中集成了 `Bun` 和 `Just`，使得容器内的开发体验与宿主机保持一致。

## 2. 踩过的坑与解决方案

| 遇到的问题 | 原因分析 | 最终对策 |
| :--- | :--- | :--- |
| **`unzip: not found`** | Bun 安装脚本依赖 `unzip` 进行解压 | 在 `Dockerfile` 中添加 `unzip` 到安装列表 |
| **`Fetch Failed` (网络下载失败)** | Ubuntu 默认源在国内访问波动较大 | 在 `Dockerfile` 中加入换源命令（阿里云镜像） |
| **`sh not found` (Just 运行报错)** | Just 默认在 Windows 下寻找 `sh` 脚本解释器 | 在 `justfile` 顶部设置 `set windows-shell` |
| **`Invalid reference format`** | Windows 绝对路径中的冒号与 Docker 路径映射冲突 | 在 `justfile` 中改用 `${PWD}` 变量并加强引号包裹 |

## 3. 技能提升点
- **前端类比**：理清了 `ctx` (Context) 在 TUI 库中的枢纽作用。
- **DevOps 基础**：初步掌握了 `Dockerfile` 的优化（换源、补全依赖）和 `justfile` 的跨平台配置。
- **Docker 理念**：理解了“容器做沙盒，宿主机做编排”的开发流模式。
