## 测试页面
### `GET` `/api/word-bench`
- `required_phrases` - 获取同一个 Source ID 的词语，至少 1 个；至多 3 个。
- `scenario` - 请求 Deepseek LLM 返回一个场景提示，帮助用户更快地进行造句。

```JSON
{
	"required_phrases": [
		{ "word":"a solid coping mechanism",  "id": 279 },
		{ "word":"in the boss's obit",  "id": 280 },
		{ "word":"keep your head straight",  "id": 281 }
	],
	"scenario": "项目失败，老板怒视着你。会议室里空气凝固，同事们低头不语。你深吸一口气，需要靠一种可靠的应对机制，在老板的怒火范围内，保持头脑清醒。"
}
```
请求成功后，创建一笔数据到 DB 中。DB 可以叫 `{ModelName}`。
```Python
from django.db import models

class PracticeRecord(models.Model):
    # 1. 情景（考卷）
    scenario_text = models.TextField(verbose_name="情景原文")
    
    # 2. 回答与批改（答题卡）
    user_text = models.TextField(verbose_name="用户作答")
    ai_polished = models.TextField(verbose_name="AI润色版")
    idiomatic = models.TextField(verbose_name="地道黑话版")
    
    # 3. 核心星轨数据（实现“反向搜索”的关键）
    word_nodes = models.JSONField(verbose_name="知识节点图谱")
    
    # 4. 元数据
    score = models.IntegerField(verbose_name="评分", default=0)
    created_at = models.DateTimeField(verbose_name="练习时间", auto_now_add=True)

    class Meta:
        db_table = 'practice_record'
        ordering = ['-created_at']
```

