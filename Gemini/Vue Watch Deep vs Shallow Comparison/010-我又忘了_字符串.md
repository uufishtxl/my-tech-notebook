## Q

我又忘了 字符串.trim 是什么功能了？好像是去除首尾的whitespaces？

## A

**是的，你的记忆完全正确！**

`trim()` 的功能就是：**去除字符串“最前面”和“最后面”的空白字符。**

### 核心特点

1.  **去头去尾，不修中间**： 它只清理两头，**不会** 动夹在字符串中间的空格。
    
2.  **不仅仅是“空格”**： 它去除的“空白字符（Whitespace）”包括：
    
    *   普通的空格 ( )
        
    *   制表符 (`\t`, Tab键)
        
    *   换行符 (`\n`, Enter键)
        
    *   其他所有不可见的空白符号。
        
3.  **不改变原字符串**： JavaScript 的字符串是不可变的（Immutable）。调用 `.trim()` 会**返回一个新的字符串**，原来的字符串保持原样。
    

### 代码演示

```
const str = "   Hello World!   \n";

// 1. 基本用法
const cleanStr = str.trim();

console.log(cleanStr); 
// 输出: "Hello World!" 
// (前后的空格、换行都没了)

console.log(str);      
// 输出: "   Hello World!   \n" 
// (原字符串没变，记得要用变量接住返回值！)

// 2. 中间的空格不动
const text = "我    爱    写代码";
console.log(text.trim()); 
// 输出: "我    爱    写代码" 
// (两头没有空格所以没变，中间的空格完全保留)

```

### 兄弟方法（如果你只想去一头）

*   **`.trimStart()`** (或 `.trimLeft()`): 只去**开头**的空白。
    
*   **`.trimEnd()`** (或 `.trimRight()`): 只去**结尾**的空白。
