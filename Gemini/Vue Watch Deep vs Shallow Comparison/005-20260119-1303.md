## Q

快速解释 some 函数

## A

一句话概括：**只要有一个满足，就返回 `true`**。

`some` 是数组的一个方法，用来检测数组中**是否至少有一个元素**符合你指定的条件。

### 核心逻辑

1.  它会遍历数组。
    
2.  **一旦找到第一个**符合条件的元素，它就**立刻停止**遍历（短路），并返回 **`true`**。
    
3.  如果遍历完所有元素都没找到，才返回 **`false`**。
    

### 代码示例

```
const scores = [50, 45, 80, 30];

// 问：有没有人及格（大于等于60分）？
const hasPass = scores.some(score => score >= 60);

console.log(hasPass); // true
// 解释：遍历到 80 时，满足条件，立刻返回 true，不再看后面的 30。

```

方法

逻辑

比如：全班有一人没交作业

**`some`**

**有没有人**...

返回 `true` (有人没交)

**`every`**

**是不是所有人**...

**`find`**
