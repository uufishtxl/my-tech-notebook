- **用户注册/登录**：用户在 Lingua Workbench 网页点击“Google 登录”，系统静默为他创建了数据库 `User`。
    
- **生成插件凭证**：用户进入你的网页后台（比如一个“设置”页面），点击**“生成 Chrome 插件专属 Token”**。此时 Django 会为这个用户生成一条长期有效的 DRF Token。
    
- **配置插件**：用户把这串长长的 Token 复制，粘贴进 Chrome Extension 的设置框里。
    
- **各司其职**：从此以后，用户在网页端靠 Google+JWT 冲浪，插件在后台靠长效 Token 默默向数据库打入抓取来的数据。**两者在同一个 Django 后端里并行不悖，互不干扰！**
