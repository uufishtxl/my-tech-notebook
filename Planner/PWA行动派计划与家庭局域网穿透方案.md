# PWA 行动派计划与家庭局域网穿透方案

> [!NOTE]
> 这份计划书记录了如何将本地的工具化应用（如 Pomodoro），在不脱离现有一套后端大脑（DRF）的前提下，通过 Vue/Vite 开发 PWA 部署为沉浸式的“原生质感”手机应用，同时采用极其安全的内网打洞策略，实现真正的跨域漫游。

---

## 🚀 阶段 1：开发 Vue3 + Vite 的独立移动端 PWA

**目标**：在 `lingua-workbench` 中建立一个与原 `frontend` 纯并行的新应用层。不需要向苹果交保护费（99刀），不需要重新签名（7日过期），只需浏览器“添加到主屏幕”。

### 1.1 项目初始化与防干扰结构
- **动作**：与 `frontend` 和 `chrome_extension` 同级，新建 `mobile_pwa` 目录。
  ```bash
  # 在项目根目录执行
  npm create vite@latest mobile_pwa -- --template vue-ts
  ```
- **核心依赖**：安装并配置 `vite-plugin-pwa` 插件。
- **UI 适配**：彻底抛弃 PC 端的宽屏思维，用纯 CSS/Tailwind 进行移动端（竖屏）响应式开发。把 Pomodoro 组件强行撑满屏幕。

### 1.2 神奇的 Manifest 配置
- 编写 `manifest.json` 或直接在 `vite-plugin-pwa` 配置项里写死：
  - 定义 App 名称（例如 "Lingua Pomo"）。
  - 设置各种尺寸的 Icon。
  - **核心**：指定 `display: "standalone"` 或 `fullscreen`，告诉手机：“屏蔽那个丑陋的浏览器地址栏！”

### 1.3 第一次真机体验
- 保持电脑上 `npm run dev --host` 开启，使用手机在同一家庭 Wi-Fi 下访问。
- 使用 Safari 选择 **“分享” -> “添加到主屏幕”**。
- 关掉 Safari，从桌面上享受你的原生质感应用。

## 🛡️ 阶段 2：后端安全穿透战 (脱离 家庭 Wi-Fi)

**目标**：出门在外（使用蜂窝网络）依然可以打通家里电脑里的 Django 服务。**绝对禁止路由器直接暴漏公网端口**（防扫号与勒索）。

### 方案 A：个人独享虚拟局网 (Tailscale / 推荐度 ⭐️⭐️⭐️⭐️⭐️)
这是最稳、最零负担、防御力满分的极客方案。
- **部署**：
  1. 家庭主服务器（跑 Django 的电脑）安装 Tailscale。
  2. iPhone/iPad 安装 Tailscale App 登录同一账号。
- **配置**：它会自动给两端分配虚拟 IP（例如 `100.x.x.x`）。
- **联调**：将 PWA（手机端）代码中的 Axios `baseURL` 改为这个虚拟 IP。
- **日常使用**：出门时只要手机挂着 Tailscale 这个 VPN，就能瞬间回到家中，安全系数爆表。（只有配置在这个私网中的设备可见）。

### 方案 B：公网发布 / 商业级内网穿透 (Cloudflare Tunnels / 推荐度 ⭐️⭐️⭐️⭐️)
这是未来炫技、分享给朋友或者组建小型工作流的究极奥义。
- **部署**：
  1. 家中电脑跑一个极轻的 `cloudflared` 守护进程。
  2. 买个便宜的个性域名（套在 Cloudflare 上）。
- **配置**：把家里的 `localhost:8000` 端口与 Cloudflare 云端强制加密绑定，如 `api.pomodoro.you.com`。
- **防御加持**：开启 CF 的 Zero Trust，可以添加邮箱甚至 GitHub 拦截页面（谁连都得先登录）。
- **日常使用**：不需要在手机挂任何 VPN 软件，这成为了一个真正意义上全网可以访问的安全接口！你的 PWA 直接写死 `baseURL="https://api..."`，在哪用都丝滑。
