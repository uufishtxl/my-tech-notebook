# Python 类私有化与 Name Mangling

> [!NOTE]
> 了解 Python 如何通过语法糖和约定来实现面向对象中的“封装”和“私有化”。

---

## 1. 成员变量的三种可见性

### 1.1 公开 (Public)
- **特征**：没有任何前缀（如 `status`）。
- **约定**：默认全公开，外部可以任意读写。

### 1.2 受保护 (Protected)
- **特征**：单下划线前缀（如 `_protected_var`）。
- **约定**：这仅仅是“君子协定”。Python 不会强行阻止访问，但它在告诫开发者：**“这是内部细节，除非你很清楚后果，否则别在外部碰它。”**

### 1.3 私有 (Private / Name Mangling)
- **特征**：双下划线前缀（如 `__private_var`）。
- **机制**：Python 并不真正支持硬连接级的私有域。它通过 **名称修饰 (Name Mangling)** 机制，将该变量秘密更名为 `_ClassName__private_var`。
- **目的**：主要为了**防止在继承体系中发生属性名冲突**。父类和子类如果都有 `__var`，它们在底层会被重命名为不同的名字，从而杜绝误盖。

---

## 2. 知识点：`__init__` 与内置函数
- 开头结尾都是双下划线（如 `__init__`, `__str__`）的方法被称为 **魔术方法 (Dunder Methods)**。
- 它们有特殊用途，**不属于**上述的私有化机制范畴，严禁在自定义变量中模仿这种“两头双划线”的命名方式。
