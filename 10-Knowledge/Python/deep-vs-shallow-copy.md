# Python 深拷贝与浅拷贝 (Deep vs Shallow Copy)

## 核心区别
| 类型 | 方法 | 描述 | 嵌套对象行为 |
| :--- | :--- | :--- | :--- |
| **引用赋值** | `b = a` | 只是起个别名，指向同一个对象 | **完全同步** |
| **浅拷贝** | `list.copy()`, `[:]`, `copy.copy()` | 复制最外层容器，内部元素仍引用原对象 | **外层独立，内层共享** |
| **深拷贝** | `copy.deepcopy()` | 递归复制所有层级，完全独立 | **完全独立** |

## 代码演示 (必背坑点)

### 1. 浅拷贝 (Shallow Copy)
```python
a = [[1], [2]]
b = a.copy()

# 修改外层：a 不受影响
b.append([3]) 
print(a) # [[1], [2]]
print(b) # [[1], [2], [3]]

# 修改内层（嵌套对象）：a 也会变！
b[0][0] = 999 
print(a) # [[999], [2]]  <-- 坑在这里
print(b) # [[999], [2], [3]]
```

### 2. 深拷贝 (Deep Copy)
```python
import copy
a = [[1], [2]]
b = copy.deepcopy(a)

b[0][0] = 999
print(a) # [[1], [2]]    <-- a 安全了
print(b) # [[999], [2]]
```

## 什么时候用？
- 一般简单列表用浅拷贝够了。
- 如果列表里存的是 Mutable 对象（List, Dict, Class Instance），且你要修改它们又不希望影响原件，必须用 `deepcopy`。
