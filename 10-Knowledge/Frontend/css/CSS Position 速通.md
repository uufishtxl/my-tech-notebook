| **属性**       | **参照物 (定位基准)**       | **文档流 (占位)**            | **核心应用场景**                                      |
| ------------ | -------------------- | ----------------------- | ----------------------------------------------- |
| **static**   | (默认值) 浏览器正常排版        | ✅ 占位                    | 默认状态，没什么好说的。                                    |
| **relative** | **自己原来的位置**          | ✅ **占位** (灵魂出窍，肉体还在)    | 1. **微调**位置。<br>2. **给 absolute 当爸爸** (作为定位基准)。 |
| **absolute** | **最近的非 Static 祖先**   | ❌ **不占位** (完全悬浮)        | 1. 图标右上角的红点。<br>2. 覆盖在图片上的文字。<br>3. 下拉菜单。       |
| **fixed**    | **浏览器窗口 (Viewport)** | ❌ **不占位** (完全悬浮)        | 1. 永远在底部的“回到顶部”按钮。<br>2. 遮罩层 (Modal Mask)。      |
| **sticky**   | **滚动容器 + 父元素边界**     | ✅ **占位** (表现像 Relative) | 1. 表格头 (thead)。<br>2. 侧边栏目录。<br>3. 列表分组标题。      |
### `sticky` 的工作原理和生效条件

>**问题**：`position: sticky` 的工作原理是什么，它需要什么条件才能生效？

需要设置 `top/bottom`阈值，且父元素不能`overflow: hidden`
**本质原理 (Hybrid Mode)**：
- **未达到阈值时**：表现得像 `position: relative`（占位，随文档流滚动）。
- **达到阈值时**：表现得像 `position: fixed`（固定在视口），**但是**！
- **边界限制**：它的“固定”是有范围的。它**死也出不去父容器（Parent）的范围**。如果父容器滚出了屏幕，它也会被带走。
