| **特性**   | **<br>computed<br>** | **<br>method<br>**  |
| -------- | -------------------- | ------------------- |
| **缓存机制** | **✅ 有缓存** (基于依赖)     | ❌ 无缓存 (每次运行)        |
| 更新时机     | 仅在**依赖变化**时重新计算      | 每次**组件重渲染**时都会执行    |
| 调用方式     | 像属性一样访问 (不加括号)       | 像函数一样调用 (需要括号 `()`) |
| 性能消耗     | 低 (复用上次结果)           | 高 (可能重复执行复杂计算)      |
| 适用场景     | **派生数据** (过滤、求和)     | **事件响应**、需要传参的逻辑    |
