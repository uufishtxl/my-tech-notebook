
## 2xx 系列 - 成功

“老板，任务搞定！”

|**状态码**|**英文名**|**场景 / 人话**|**记忆重点**|
|---|---|---|---|
|**200**|OK|**标准成功**。GET 拿到了数据，PUT 更新成功了。|最常见的。|
|**201**|Created|**创建成功**。你发了 POST 请求，新资源（比如新用户、新文章）造出来了。|**DRF 的 `create` 方法默认返这个**。|
|**204**|No Content|**删掉了/搞定了，不用回话**。通常用于 **DELETE** 请求。任务完成了，但我没什么数据需要返给你，节省带宽。|**面试必考：DELETE 操作返什么码？**|

## 3xx 系列 -  重定向

_“老板，东西不在我这儿，你去那边找。”_

|**状态码**|**英文名**|**场景 / 人话**|**记忆重点**|
|---|---|---|---|
|**301**|Moved Permanently|**永久搬家**。以前的 URL 废了，搜索引擎（SEO）会把权重转移到新地址。浏览器下次会**自动**访问新地址。|**http 变 https** 通常用这个。|
|**302**|Found (Temporary)|**临时出差**。只是暂时去别的地方，旧地址过两天还能用。|比如**登录跳转**（未登录跳到 Login 页）。|
|**304**|Not Modified|**你用缓存吧**。**（这就是你要找的那个！）**<br><br>  <br><br>客户端问：“服务器，这图改没改？”<br><br>  <br><br>服务器说：“没改，你自己拿浏览器的缓存用吧。”|**性能优化核心**。不传数据体，极快。|
## 4xx 系列 - 客户端错误

_“是你（前端/用户）的问题，别怪服务器。”_

|**状态码**|**英文名**|**场景 / 人话**|**记忆重点**|
|---|---|---|---|
|**400**|Bad Request|**参数烂了**。你传的 JSON 格式不对，或者缺了必填项，或者字段类型错了。|前端传参错误最常见。|
|**401**|Unauthorized|**你谁啊？（未登录）**。没有 Token，或者 Token 也就是密码过期了。|**身份认证 (Authentication)** 失败。|
|**403**|Forbidden|**我知道你是谁，但你不配。（无权限）**。你登录了（有Token），但你是个普通用户，想删管理员的数据。|**权限控制 (Permission)** 失败。<br><br>  <br><br>**面试必问：401 和 403 的区别？**|
|**404**|Not Found|**查无此人**。URL 写错了，或者 ID=9999 的书不存在。|这个不用多说。|
|**405**|Method Not Allowed|**动词用错了**。接口只允许 `GET`，你非要 `POST`。|DRF 经常见，如果你忘了写 `post` 方法。|
|**429**|Too Many Requests|**你慢点刷！**。请求太频繁，被服务器限流（Throttling）了。|爬虫最怕这个。|

## 5xx —— 服务器错误 (Server Error)

_“是我（后端/运维）的问题，我有罪。”_

|**状态码**|**英文名**|**场景 / 人话**|**记忆重点**|
|---|---|---|---|
|**500**|Internal Server Error|**后端炸了**。代码抛异常了（Bug），或者数据库连不上了。|看到这个赶紧去修代码。|
|**502**|Bad Gateway|**网关坏了**。通常是 **Nginx** 还在，但它后面的 **Django/Gunicorn** 挂了，Nginx 联系不上后端。|运维/部署问题。|
|**504**|Gateway Timeout|**超时了**。Nginx 联系上了 Django，但 Django 算得太慢（死循环或数据库卡死），Nginx 等得不耐烦挂断了。|数据库查询太慢。|
