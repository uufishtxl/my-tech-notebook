# Django 速成课笔记

这是一个从零开始构建 Django 项目的核心知识点总结。

**学习路径：**

1.  [**页面一：安装、概念与项目启动**](./01-setup-concepts.md)
    * 学习 Django 的 MVT 架构，安装环境，并创建你的第一个项目和 App。

2.  [**页面二：模型与数据库 (Models & DB)**](./02-models-database.md)
    * 定义数据模型 (Models)，执行数据库迁移 (Migrations)，以及如何从 SQLite 切换到 MySQL。

3.  [**页面三：视图、模板与路由 (Views, Templates, URLs)**](./03-views-templates-urls.md)
    * 处理用户请求 (Views)，渲染 HTML 页面 (Templates)，以及如何将它们通过路由 (URLs) 绑定在一起。

4.  [**页面四：表单与后台管理 (Forms & Admin)**](./04-forms-admin.md)
    * 创建表单 (Forms) 来接收用户数据，以及配置 Django 强大的内置后台 (Admin)。
